# ActionShap generated paper assets

These assets were generated from a 50-user smoke run over five seeds. They are **not final paper evidence**. The next run should use at least 500 users, the converged Monte Carlo budget, and the updated faithfulness/actionability figures.

Primary protocol: fixed sampled evaluation sets with target coverage 1.0, `n_max=20`, `rho=0.5`, and `B=2`.
