# ActionShap Overleaf submission package

This folder uses the same Springer Nature `sn-jnl` class, numeric
Math--Physical Sciences bibliography style, `latexmkrc`, and directory layout
as the working `signalshap-overleaf.zip` package. `actionshap.tex` is the main
document; generated figures are under `figures/`, tables under `tables/`, and
all 47 ActionShap references are in `actionshap-bibliography.bib`.

Compile in Overleaf with pdfLaTeX and BibTeX. The expanded audit appendices are
intentionally included so the manuscript is at least 30 pages after the
validated tables are typeset; no placeholder or unresolved citation is used.
