# Springer Nature journal template

This directory contains the `sn-jnl` journal class and `sn-basic` bibliography style, obtained from the Springer Nature journal template family (December 2024 author-support package lineage). `paper.tex` selects `pdflatex,sn-basic` and keeps the content-first Springer structure. Replace the placeholder correspondence email and affiliation with the authors' submission metadata before submission.
