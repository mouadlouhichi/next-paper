## Contents

- `paper.tex`: Springer Nature manuscript source copied from `paper/paper.tex`.
- `paper.bib`: manuscript bibliography.
- `sn-jnl.cls`, `sn-basic.bst`: Springer Nature LaTeX template files.
- `final/`: the complete tracked final result-assets tree copied from `paper/final/`, including figures, tables, compressed user-seed metrics, manifests, and the generated results summary.

## Provenance

The package is a reproducible snapshot of the last commit's tracked paper assets. The raw JSON experiment archive is not duplicated here because it is managed separately under the results-release workflow. Its externally generated checksum, when available, must be verified against the release manifest before submission. Dataset source files are intentionally not copied into this paper package.
