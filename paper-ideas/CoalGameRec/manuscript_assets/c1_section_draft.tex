\subsection{Confirmatory study with matched validation-informed controls (C1)}\label{subsec:c1}

The primary frozen study compares validation-guided game attribution against non-game controls that have \emph{no} validation access. To isolate the contribution of the game structure from the contribution of validation access itself, we ran a confirmatory study (C1) that adds two matched validation-informed non-game controls with the same validation item available to the Shapley/LOO games:
\begin{itemize}
    \item \textbf{valid-sim} (history reweighting): $w_j = \max(0, \cos(\mathbf{e}_j, \mathbf{e}_{i_u^+}))$ applied through the identical native intervention~(\ref{eq:rerank});
    \item \textbf{valid-linear} (candidate-side linear reranker): $s'_{ui} = \mathrm{zscore}(b_{ui}) + \lambda_{\text{attr}}\,\mathrm{zscore}(\cos(\mathbf{e}_i, \mathbf{e}_{i_u^+}))$, the strongest non-game reranker with validation access.
\end{itemize}
Both share the a-priori $\lambda_{\text{attr}}=0.10$; neither uses coalition values or attribution. C1 re-executes the frozen protocol (identical hyperparameters, seeds 42--46, archived splits) on CPU; deviations from the v3 runs (hardware, torch re-execution, vectorized negative sampler, one shared propagation per batch, Shapley-MC not re-run for compute reasons) are recorded in each run's \texttt{manifest.json}. Code: \texttt{scripts/run\_matched\_controls.py}, \texttt{coalgamerec/rerank.py}.
